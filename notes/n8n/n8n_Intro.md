# 甚麼是 n8n?

[n8n](https://github.com/n8n-io/n8n) 是一款 [Source available](https://en.wikipedia.org/wiki/Source-available_software) 的自動化流程工具，可自行架設在本地或雲端，也能使用官方或第三方的託管服務。
與 [Zapier](https://zapier.com)、[Make](https://www.make.com/) 等其他自動化工具相比，n8n 的自由度更高：

- 可以撰寫**自訂節點（Custom Nodes）**
- 可以整合**任意 API**
- 可以在流程中**插入 JavaScript / Python**
- 支援 **AI Agent、RAG、LLM 工具整合**

它既能用視覺化方式編排流程，也能在需要時加入程式碼，是一款兼具彈性與可擴充性的自動化平台。
