# Documentation Intro

這裡收錄我開發的 Unreal Engine 工具與相關研究的使用文件,包含安裝步驟、設定教學與常見問題排解。
目前的專案有：

## 專案

### NGSVM - Non-Green Screen Video Matting Unreal 5.7 Plugin
這是一個基於 Unreal Engine 5.7 的插件，用於即時 AI 去背，它基於 Unreal Engine 的 NNE（Neural Network Engine）構建。可以在 CPU 或 GPU（DirectML）上運行 RVM（(Robust Video Matting)）或 MODNet 模型，無需綠幕即可對即時視訊/相機畫面或單張靜態影像進行去背。

### Unreal Rivermax ST2110 Integration
本專案針對 Unreal Engine 與 SMPTE ST 2110 的整合進行可行性研究，採用 Rivermax 作為傳輸介面，完成初步的系統架構驗證。包含架構設計、基本安裝與除錯流程。
